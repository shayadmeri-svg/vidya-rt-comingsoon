Start with the learning goal

Before choosing questions, decide what the test should tell you. A short check after a lesson needs a different paper from a full mock.

  • Choose the subject and chapters you want to assess.
  • Decide which concepts need direct checks and which need application.
  • Select question types and set the marks and time limit.
  • Review the paper for coverage, clarity, and avoidable clues in the options.

Run the assessment your way

Make the instructions clear before students begin. Use the controls that fit the assessment.

  • Assign the intended class or students.
  • Set the opening time and answer-review rules.
  • Check the paper and student experience before the session.
  • Use teacher controls such as extra time or reopening an attempt when appropriate.

Example: a chapter check after teaching

A short chapter test can tell you whether the class is ready to move on. Start with a specific question about understanding.

  • Include questions that check the key idea and how students apply it.
  • Review which wrong options attract repeated responses.
  • If many students share the same gap, revisit the concept with the class.
  • If only a few students need support, choose focused individual practice.

Questions, answered.

Can teachers create chapter tests and full mocks?

Yes. VidyaRT supports choosing subjects, chapters, and question types, with marks and timing set for the paper.

Is there a free online test-maker plan?

Yes. VidyaRT Free includes lifetime quotas of 5 students, 5 tests, and 25 AI question runs. No card or trial expiry is required. Full reporting and other features depend on the plan.

Can I control when students see answers?

Yes. Teachers can set answer-review rules for the assessment. Review those settings before sharing the paper.
