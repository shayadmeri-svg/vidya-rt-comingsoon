# VidyaRT teacher landing page

Static GitHub Pages site for `vidyart.com`. It presents the teacher and institution assessment workflow and points teachers to the workspace at `https://admin.vidyart.online/`; the For students navigation points to `https://vidyart.info/`.

The page is plain HTML and CSS. Preview by opening `index.html` or serving this directory with any static file server. Keep `CNAME` as `vidyart.com` when publishing. The page uses the supplied clean symbol SVG (`vidyart-logo.svg`) with transparent background and no pale flower plate. The earlier animated SVG is retained as `vidyart-animated.svg` for reference.

Safe Exam Browser is described as an optional per-assessment mode. The implementation notes in the app repo say to pilot and validate it on supported devices before a high-stakes exam.
